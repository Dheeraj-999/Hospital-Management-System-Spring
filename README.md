# Hospital-Management-System-Spring

# UC1 – User and Role Management

## Objective
To establish the basic user structure and role management functionality for the Hospital Management System.

## Features Implemented
- Created the User entity.
- Created the Role enum.
- Defined ADMIN and PATIENT roles.
- Added user properties: ID, name, email, password, and role.
- Created UserRepository.
- Implemented finding users by email.
- Implemented checking whether an email already exists.

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Main Files
- entity/User.java
- entity/Role.java
- repository/UserRepository.java

## Concepts Learned
- Java enums
- JPA entities
- Repository interfaces
- Database mapping
- Spring Data JPA

## Outcome
The basic user and role management foundation was established for the authentication module.
